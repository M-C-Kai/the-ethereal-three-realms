# 生活技能数据库

本文件说明 `data/catalog/life_skills.json` 的 v2 静态数据结构。协议 wire 细节仍以 `docs/protocol/life-skills.md` 为准。

## 数据来源边界

- 本次技能名称、学习地点、等级上限、升级方式、品质、辨识/秘方、月光匣、珠灵术说明来自用户提供的《飘渺三界 OL》生活技能全表。
- 官方草药、矿石、丹药、月光匣的 item template id、精确地图坐标、成功率公式、材料减免公式未在资料中给出。
- 因此 `recipes` 与 `gather_targets` 中保留当前本服兼容种子，标记为 `source_status = compat_local_seed`，用于维持现有协议/背包测试。
- 四大生活技能与珠灵术不并入 `sect_combat_skill_catalog`；战斗门派技能与生活技能分库维护。

## 品质体系

`quality_grades` 统一登记四品：

1. 普品
2. 佳品
3. 珍品
4. 绝品

适用对象：

- 草药：百草术采集产物
- 矿石：采矿术采集产物
- 丹药：丹药术炼制产物

丹药高品概率受两个因素影响：

- 丹药术技能等级
- 炼制材料品质

具体概率公式未确认，后续应等客户端或原始服务端资料再落公式。

## 解锁体系

`recognition_unlocks` 记录辨识/秘方：

| 技能 | 初学解锁 | 后续解锁 |
|---|---:|---|
| 百草术 | 2 种草药辨识 | 找百草术训练师消耗银两和经验 |
| 采矿术 | 2 种矿石辨识 | 找采矿术训练师消耗银两和经验 |
| 丹药术 | 2 种丹方 | 找丹药术训练师消耗银两和经验 |

`special_unlocks` 记录特殊道具/条件：

- `pill_vessel`：盛丹器皿，药店购买，用于炼丹。
- `luban_secret_record`：《鲁班秘录》，高级藏宝图任务或天关副本概率获得，用于红色月光匣。
- `spirit_crystal`：灵晶石，仙灵塔获取，用于快速补充灵力。
- `jade_slip_transform`：玉简·化，天书真人购买，用于通过化技突破灵力上限。

## 工巧术月光匣

`craft_products` 登记三段：

| 等级 | 产物 | 条件 |
|---|---|---|
| 1–19 | 绿色月光匣 | 无特殊解锁 |
| 20–39 | 蓝色月光匣 | 无特殊解锁 |
| 40–50 | 红色月光匣 | 需《鲁班秘录》 |

三种月光匣均可储存飞行次数。等级越高可储存次数越多；升级工巧术可提高制作成功率并减少材料消耗。具体次数、成功率、材料消耗公式未确认。

## 珠灵术

`spirit_bead_conversions` 登记五行灵力与属性关系：

| 灵珠 | 对应属性 |
|---|---|
| 金灵珠 | 力量 |
| 木灵珠 | 耐力 |
| 水灵珠 | 敏捷 |
| 火灵珠 | 智力 |
| 土灵珠 | 精神 |

用途：在五行锻造炉中进行五行锻造，提升装备后天属性。

限制：

- 需要灵力达到最低合成门槛。
- 灵力越高，单次可合成数量越大。
- 灵力无法快速自然恢复，需在线刷怪提高回复速度；也可通过仙灵塔获取灵晶石补充。
- 灵力补满后，可在天书真人处购买不同等级的玉简·化，通过化技突破灵力上限。
