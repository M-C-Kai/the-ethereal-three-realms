## 网络层公共链

```text
client encode_frame / APK writer
→ TCP send
→ server.handle readexactly(length)
→ optional GameCipher.decrypt(fields)
→ decode_payload
→ numeric message_id dispatch
→ business mutation/RoleStore.save
→ encoder function(s)
→ LocalGameServer._send
→ optional encrypt_server_frame
→ TCP drain
→ APK main/e numeric dispatcher
```

来源：`protocol.py:147-234`、`server.py:1706-1724,1865-2449`、`references/CLIENT_EVIDENCE.md:5-18`。

逐条消息的字段与业务入口已在消息总表和模块文档覆盖；项目使用数字分支，没有独立 Handler 类或 Gateway 转发层。
