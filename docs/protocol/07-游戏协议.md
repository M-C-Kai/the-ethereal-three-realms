# 地图、物品与战斗协议

## 地图链

- C→S `1123`（初始化确认）→ S→C `1123(action0,version,text)` + `1110(0,mapId,mapId,mapName)`。来源：`server.py:1988-1997,1071-1085`。
- C→S `1010(short 12)` → S→C `1010/action11`、五段 `1407`、`1010/action12(status=1)`。1407：0=`byte mapType,width,height`；1=`short len,bytes definitions`；3=tiles RLE；5=collision；7=mirror。来源：`server.py:1635-1675,2008-2017`。
- C→S `1010(short 13)` → S→C `1010/action13,14,105` + `1126` 怪物/传送点。来源：`server.py:1678-1691,2018-2040`。
- 通用 1010 响应固定：`int roleId,short x,short y,int 0,int status,short action`。来源：`server.py:1088-1098`。
- 2031 交互：`int objectId,int 0,short x,short y,short action,short 0`；服务端也接受旧路径 `1010(short 7,int objectId)`。来源：`server.py:1152-1165,2041-2081`。

## 人物与物品

- 1006：`int propertyCount` + 85 个顺序属性 0..84 + `int serverTime`；属性 31/32 必须是 long，其余包含 int/string。完整赋值见 `server.py:630-692`。
- 1017：`byte subtype,int roleId,int pairCount,(byte property,int value)*`。经验的高 32 位另用属性 85/86。来源：`server.py:770-831`。
- 1008 固定前 16 字段：`byte op,int instanceId,short quantity,short maxQuantity,byte position,int flags,int price,int templateId,string name,short itemFlags,short actionFlags,byte requiredLevel,short icon,int expires,short group,short order`。装备再跟 `4*short + 5*byte + 5*byte + 5*short`。来源：`server.py:886-923`。
- 1009 请求/响应关系详见消息总表；成功操作可能附带 1008 和 1017。完整业务分支：`server.py:2320-2447`。

## 战斗闭环

1. 2031/1010-7 命中怪物 → `1040/0`、两条 `1048`、`1040/1`。
2. C→S 1041 命令 → S→C 一或两条 `1042`（玩家攻击、怪物反击）+ `1040/2`。
3. 客户端动画结束 → C→S `1040/2,round`；服务端进入下一回合或结算。
4. 胜利：`1040/4 → 1010/18 → 1017 → 1008 → 1123 → (1129 或 1049/3)`；失败只发 `1040/4`。

1040/action1 和 2 均为：`byte action,int round,byte reserved,int timer,short menuState,string reserved,short targetState,string reserved,byte ready`；action0/4 只有一个 byte。来源：`server.py:1168-1198,1608-1632`。

1042 普攻字段：`int round,senderId,targetId,byte type=1,byte hitCount,byte 0,int senderFx,int targetFx,string label,int effectCount,int effectTarget,int flags,int effectType=22,int negativeDamage,string ''`。来源：`server.py:1541-1579`。

1048 有 22 个字段，精确类型与意义注释见 `server.py:1201-1254`；资源请求 1502 与 1501/1503 的字段见 `server.py:1335-1538`。这部分属于实际战斗资源加载链。
