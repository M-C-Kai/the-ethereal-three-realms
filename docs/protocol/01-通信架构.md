# 通信架构

```text
Android APK Client
  ├─ TCP connection #1: 登录、服务器列表、选服
  └─ TCP connection #2: 游戏握手、角色、地图、物品、战斗、心跳
                         ↓
             Python asyncio LocalGameServer
                         ↓
          RoleStore(JSON) + 本地地图/角色/图片资源
```

- 单进程 `asyncio.start_server` 监听同一 host/port，无 Gateway、RPC 或内部 S→S 链路。来源：`implementation_staging/server.py:2466-2470`、`implementation_staging/config.json:2-4`。
- 客户端在收到 `1052` 跳转后关闭登录连接并连接返回地址；游戏连接首包仍为 `1052`。来源：`implementation_staging/server.py:585-595`、`implementation_staging/test_client.py:53-65`。
- TCP 包边界通过 2 字节长度字段处理，读取采用 `readexactly`，天然处理粘包和拆包。来源：`implementation_staging/server.py:1877-1884`。
- 没有 WebSocket、UDP、HTTP、Protobuf、MessagePack。持久化 JSON 只用于服务端角色存档，不是网络序列化。来源：`implementation_staging/server.py:419-568`、`implementation_staging/protocol.py:147-234`。
- 客户端证据来自仓库保存的 smali；其索引见 `implementation_staging/references/CLIENT_EVIDENCE.md:1-27`。
