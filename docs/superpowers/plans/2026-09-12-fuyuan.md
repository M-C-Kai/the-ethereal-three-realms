# 福缘实施方案与计划

用户已确认：持久化福缘、原生列表/详情/补充/快捷升阶、每分钟消耗一点、严格大于 5000/15000 判阶、经验 +5%、二阶血量 +20%、三阶背包 +20 格。新旧角色首次赠送 1000 点；不删除到期后超额物品，未实现权益标明状态。

## 设计

- `implementation_staging/fuyuan.py`：数据验证、迁移、按时间结算、等级、购买报价和 1054 编解码；无服务器反向依赖。
- `implementation_staging/data/fuyuan.json`：17 项 APK 文案权益，标明实际开放状态；本地补充价格默认每点 1 银两，套餐 1000/5000/15000 点。此价格不是原服还原。
- `server.py`：迁移/创建时初始化，登录/请求/心跳结算，1054 非退出动作分流，1017 刷新，已有奖励、血量、容量入口应用权益。
- 原生福缘列表显示补充或升阶报价，点击行使用 APK 已有菜单“确认/取消”回传 1054 action 2；连接内保存报价，120 秒失效，确认后消耗报价，重复请求不能重复扣款。
- 阶数从剩余点数派生，时间余数保留；离线照常消耗。历史存档仅缺少福缘字段时赠送，清零后不会重复赠送。
- 不自动授予未实现奖励。过期存档不删除道具；容量不足禁止新入包。
