# Pet Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the native pet core loop: schema migration, rename, release, stat allocation, authoritative derived properties, and preserve existing deploy/walk behavior.

**Architecture:** Keep APK wire encoding in `pet_protocol_core.py`, persistent instance/schema rules in `pet_model.py`, and state transitions in `pet_service.py`. `server_pets.py` remains a thin bridge that translates exact native requests into service calls and returns native response frames. Existing `pet_protocol.py` stays as a compatibility facade during the migration so current imports and phone-tested behavior do not break.

**Tech Stack:** Python standard library, unittest, existing typed TLV `protocol.py`, APK DEX/smali evidence.

**Spec:** `docs/superpowers/specs/2026-09-12-pet-system-design.md`

## Global Constraints

- Use APK-native UI and wire protocol only; do not invent message IDs, subcommands, or field types.
- Preserve `data/roles.json`; all schema changes are idempotent migrations.
- Exact `byte/short/int/string` types are mandatory.
- Core server remains Python standard-library-only.
- Every encoder, decoder, migration, and state transition gets a unit test.
- Existing phone-verified `1127/action=1`, `1127/action=9`, `1130/action=10`, `1130/action=48`, `1127/action=13`, and `1010/action=102` behavior must remain unchanged.

```python
def test_rename_native_layout(self):
    fields = [byte(15), integer(123), string('灵狐')]
    self.assertEqual(parse_pet_rename_request(fields), (123, '灵狐'))
    mid, out = decode_frame(pet_rename_frame(123, '灵狐'))
    self.assertEqual(mid, 1130)
    self.assertEqual([(f.type_id, f.value) for f in out], [
        (TYPE_BYTE, 15), (TYPE_INT, 123), (TYPE_STRING, '灵狐')])

def test_release_native_layout(self):
    fields = [byte(1), integer(123)]
    self.assertEqual(parse_pet_release_request(fields), 123)
    mid, out = decode_frame(pet_release_frame(123))
    self.assertEqual(mid, 1130)
    self.assertEqual([(f.type_id, f.value) for f in out], [(TYPE_BYTE, 1), (TYPE_INT, 123)])

def test_stat_allocate_native_layout(self):
    fields = [integer(123), short(2), short(1), short(2), short(3), short(4), short(5)]
    self.assertEqual(parse_pet_stat_request(fields), (123, (1,2,3,4,5)))
```

- [ ] **Step 3: Implement exact parsers/encoders**

Protocol locks from APK:
- Rename C→S/S→C: `1130 [BYTE 15, INT petId, STRING newName]`.
- Release C→S/S→C: `1130 [BYTE 1, INT petId]`.
- Pet stat allocation C→S: `1128 [INT petId, SHORT 2, SHORT d0, SHORT d1, SHORT d2, SHORT d3, SHORT d4]`.
- Pet incremental update S→C: `1134 [BYTE 0, INT petId, INT count, (BYTE propertyId, typed value)*]`.

Reject numerically-equal fields with the wrong type ID.
