## 1. 项目总览

本项目是《飘渺三界2》Android 客户端的本地兼容服务原型，目标是让手机只连接局域网内的本地服务，逐步补齐客户端已有的玩法协议。

### 已实现链路

```
登录 → 本地一区 → 角色列表 → 创建/删除角色 → 进入地图 → 1126 试炼妖兽实体
→ 背包 → 人物四页面板 → 装备/卸下/使用物品 → 长安传送阵 → 昆仑导师 → 门派技能学习
```

### 技术栈

- Python asyncio TCP 服务（纯标准库）
- 协议层：自定义 TLV 帧格式 + 游戏阶段加密（`GameCipher`）
- 数据持久化：JSON 文件（`data/roles.json` 等）

## 2. 架构概览

### 三层职责

```
┌─────────────────────────────────────────────┐
│  server.py                                  │
│  - 依赖装配（实例化系统、注入存储/事件总线）  │
│  - 系统总线路由（SystemRouter.dispatch）      │
│  - 网络收发（asyncio TCP、加密、心跳）        │
└─────────────────┬───────────────────────────┘
                  │
┌─────────────────▼───────────────────────────┐
│  app/router.py  — SystemRouter              │
│  按 MessageID 分发到唯一系统 handler          │
└─────────────────┬───────────────────────────┘
                  │
┌─────────────────▼───────────────────────────┐
│  systems/<name>/                            │
│  handler.py  → 协议入口和路由注册             │
│  service.py  → 业务规则和状态流转              │
│  protocol.py → 协议字段编码/解码              │
│  registry.py → 静态目录加载和校验              │
│  events.py   → 跨系统事件名和载荷定义          │
└─────────────────────────────────────────────┘
```

### 消息号优先级

路由注册顺序决定优先级（从上到下）：

1. `team` — 独占 1023
2. `social` — 先于 role/inventory 剥离 1089/byte-2 与 1009/81
3. `pet` — 先于 role 认领 1103
4. `role` — 先于 map 认领 1010/36 与登出页 1054
5. `task` — 先于 map 认领任务型 1145
6. 其他系统（map / inventory / battle / skill / shop / gang / consignment / fuyuan）

## 3. 核心流程

### 3.1 登录流程

```

  │  1055 (注册/登录)  │
  │──────────────────>│  AccountStore 验证

  │                   │
  │  1052 (跳转+加密)  │
  │<──────────────────│  GameCipher 初始化
```

### 3.2 角色选择流程

```
客户端                服务端
  │  1080 (角色列表)   │

  │<──────────────────│
  │                   │
  │  1080 (创建角色)   │

  │<──────────────────│

  │──────────────────>│  角色进入地图

  │  1123 (地图初始化) │

```

```
  │<──────────────────│
  │                   │

  │<──────────────────│
```

## 4. 模块详解

### 4.1 角色系统 (role)

**目录**：`systems/role/`

**功能**：

| 功能 | 消息号 | 说明 |
|------|--------|------|
| 注册/登录/改密/找回 | 1055 | AccountStore 验证 |
| 服务器列表 | 1077 | 返回本地一区 |
| 选服跳转 | 1051 | 生成会话令牌 |
| 游戏阶段加密 | 1052 | 初始化 GameCipher |
| 角色列表/创建/删除/选择 | 1080 | RoleStore CRUD |
| 人物面板属性 | 1006 | 完整属性表（0~84） |
| 角色基础扩展资料 | 1089 (byte=2) | 空集合初始化 |
| 门派/门派技能 | 1103 | sect_registry |
| 技能容器 | 1132 | 初始技能帧 |
| 属性页/神通页 | 1039 | 基础数据 |
| 升级效果 | 1500 | 协议帧 |
| 邮件 | 1129 | 请求帧 |
| 坐骑图鉴/目录 | 1024 / 1054(登出页) | 坐骑系统 |
| 主菜单预取 | 1090 / 1153 / 1061 | 安全空应答 |
| 登出确认 | 1003 / 1054 | 清理状态 |

**数据来源**：`data/roles.json`（持久化）、`data/accounts.json`

**联动关系**：

- → **地图**：选择角色后触发 `relocate_role_for_cold_login` 进入地图
- → **背包**：角色进入时初始化物品容器
- → **技能**：1132 初始化技能列表
- → **宠物**：1103 宠物子类型先于角色认领
- → **福缘**：角色属性包含福缘值
- → **社交**：角色名、外观、位置供其他玩家查看

**CharacterUpdateBus**：角色属性变更事件总线，装备/卸下/升级等属性变化时通知所有订阅系统。

### 4.3 背包系统 (inventory)

**目录**：`systems/inventory/`

**功能**：

| 功能 | 消息号 | 说明 |
|------|--------|------|
| 物品下发 | 1009 | 物品帧（装备/道具/坐骑） |
| 物品说明 | 1009 | 描述文本 |
| 物品详情 | 1032 | 属性/状态 |
| 装备/卸下 | 1009 (子类型) | 触发属性重算 |
| 使用物品 | 1009 (子类型) | 消耗品/坐骑 |
| 丢弃物品 | 1009 (子类型) | 从背包移除 |
| 强化装备 | 1009 (子类型) | 消耗材料提升 |

**数据来源**：`data/roles.json` 中的 items 字段、`item_registry`（物品模板）

**联动关系**：

- → **角色**：装备变更触发 `CharacterUpdateBus` 属性重算
- → **社交**：交易/赠送时读取背包物品
- → **商店**：购买后物品入背包
- → **寄售**：上架/下架物品
- → **地图**：坐骑穿/卸触发外观广播

**关键规则**：
- 背包分组 100 只能放装备；普通道具使用分组 150
- 装备位置 1~14 对应不同槽位
- 坐骑骑乘码 = 属性 22（精灵族），不能当武器外观

### 关键联动路径

| 触发 | 经过 | 结果 |
|------|------|------|
| 装备物品 | inventory → CharacterUpdateBus → role | 属性重算 + 广播 |
| 点击妖兽 | map → battle | 创建战斗 |
| 完成战斗 | battle → inventory + role | 掉落物品 + 经验 |
| NPC 对话 | map → task / consignment | 接任务 / 寄售 |
| 打开主菜单 | role → 预取 1403/1090/1153/1061 | 空应答 |
| 查看玩家 | social → role (find_role) | 目标属性 |
| 交易物品 | social → inventory | 物品转移 |
| 坐骑穿卸 | inventory → map (广播) | 外观同步 |
| 组队移动 | team → map | 跟随链 |
| 心跳 | role → fuyuan | 周期结算 |
